1\. 项目概述

1.1 项目背景

在数字经济与产业政策高速迭代的当下，政府、企业和研究机构每天面临海量信息的冲击。政策发布分散于数十个部委官网与地方门户，行业动态散落在众多垂直媒体与协会网站，人工监测与筛选的成本极高，且极易遗漏关键情报。

传统的信息收集方式（人工浏览、Excel 汇总、微信群转发）存在三大痛点：

• 采集效率低：研究员需逐个打开网站，复制粘贴，耗时耗力。

• 分类不精准：不同人员对同一篇文章的归类标准不一，导致知识库混乱。

• 分发渠道弱：优质内容沉淀在本地文件夹，无法自动推送至微信公众号、邮件订阅者等受众端。

1.2 产品定位

拾讯（shixun.com） 是一个面向政策研究员、产业分析师、企业战略部门及科技媒体运营者的 智能情报采集与分发平台。核心定位是：

"让有价值的信息，自动找到需要它的人。"

产品通过"自动化爬取 + AI 智能分类摘要 + 多渠道一键分发"的闭环，将原本需要数小时的人工信息整理工作压缩至分钟级，并确保内容呈现的专业性与品牌一致性。

2\. 应用场景

场景 A：每日政策监测与汇编

参与角色：政策研究员、情报中心负责人

流程：

1\. 研究员在系统中批量导入 20\~50 个目标政策网站（如国务院、工信部、各省市工信局官网）。

2\. 设定目标日期为昨日，系统凌晨自动启动爬取任务。

3\. AI 中枢对每篇文章进行分类（如"最新政策"、"新型工业化"）并生成 150 字摘要。

4\. 早晨 08:00，研究员登录系统，下载一份已排版的 Word 日报，直接呈送领导或上传至内部知识库。

价值：将原本 2\~3 小时的人工汇总压缩至 5 分钟，且分类标准统一、摘要质量稳定。

&#x20;

场景 B：行业情报自动分类与推送

参与角色：产业分析师、咨询顾问

流程：

1\. 分析师关注"人工智能"、"具身智能"、"算力"三个赛道。

2\. 系统每日从合作媒体、行业协会网站抓取文章后，自动将相关文章归入对应分类。

3\. 分析师在后台可按分类筛选、按置信度排序，快速定位高价值内容。

4\. 选中关键文章后，分析师可将其导出为带公司 Logo 和水印的专业 Word 报告，发送给客户。

价值：消除信息噪音，让分析师专注于深度解读而非信息收集。

&#x20;

场景 C：微信公众号内容自动化运营

参与角色：科技媒体运营者、协会宣传部门

流程：

1\. 运营者在文章库中勾选 3\~5 篇今日热点文章。

2\. 系统基于文章标题与分类关键词，自动合成一张品牌风格的封面头图。

3\. 运营者选择一套排版模板（如"政务蓝"或"科技黑"），系统自动将 HTML 样式降级为微信兼容的内联样式。

4\. 点击"推送至草稿箱"，内容即出现在微信公众号后台，运营者只需做最终审核即可发布。

价值：解决微信公众号排版耗时、封面图设计依赖美工的问题，实现"选题即发布"。

&#x20;

场景 D：定制化情报订阅与邮件通知

参与角色：行业从业者、投资人

流程：

1\. 用户在订阅页面输入关注主题词（如"数据要素"）、目标网站范围、接收邮箱。

2\. 系统每日 09:00 扫描过去 24 小时入库的文章，匹配标题与摘要中的关键词。

3\. 若有匹配文章，自动以 HTML 邮件形式发送汇总，包含文章标题、摘要及原文链接。

4\. 用户点击邮件底部链接可随时退订或修改关键词。

价值：用户无需每日登录平台，核心情报主动送达，降低使用门槛。

3\. 核心功能模块

3.1 自动化数据采集 (Crawler)

业务价值：解决"信息从哪来"的问题，是平台的内容源头。

核心能力：

• 支持用户批量提交网址列表与目标日期，系统自动完成全文抓取。

• 精准提取标题、发布单位、正文、发布时间、原文链接五大核心字段。

• 具备基础反爬能力（浏览器模拟、请求间隔、UA 轮换），适配政府官网、新闻媒体、行业协会等主流站点。

• 异步任务调度，支持批量任务的进度追踪与失败重试。

MVP 交付：可稳定爬取指定日期的文章，入库成功率 ≥ 90%。

&#x20;

3.2 AI 智能中枢 (AI Engine)

业务价值：解决"信息如何理解"的问题，将原始文本转化为结构化知识。

核心能力：

• 智能分类：基于 11 大预置标签（最新政策、数字经济、人工智能、数据要素、通信、申报、潜在商机、具身智能、车路云协同、新型工业化、算力），自动判断文章归属。

• 置信度控制：仅当分类置信度 ≥ 0.6 时才采纳，最多选取 Top-3 标签，避免"贴错标签"的尴尬。

• 智能摘要：生成 150\~200 字的核心摘要，突出政策要点或商业机会，而非简单摘抄首段。

• 关键词提取：为后续封面图生成与搜索优化提供语义标签。

MVP 交付：分类准确率 ≥ 85%，摘要可读性通过人工抽检。

&#x20;

3.3 结构化入库与每日报表 (Storage \& Reporting)

业务价值：解决"信息如何沉淀"的问题，形成可检索、可回溯的知识资产。

核心能力：

• 文章元数据与 AI 加工结果统一存入数据库，支持按日期、分类、来源单位多维筛选。

• 每日自动生成标准格式 Word 日报，含封面、导读、正文列表与原文链接。

• 日报支持一键下载，可直接用于内部汇报或领导呈送。

MVP 交付：每日 00:30 自动生成前一日日报，人工审核后无排版错误。

&#x20;

3.4 微信公众号分发 (WeChat Automation) — 预留

业务价值：解决"信息如何传播"的问题，打通微信生态这一核心渠道。

核心能力：

• 将前端精美排版自动降级转换为微信图文兼容的内联样式，视觉效果对标专业编辑器。

• 自动合成品牌封面图（插画底图 + 标题文字叠加）。

• 一键推送至微信公众号草稿箱，运营者只需做最终审核。

MVP 交付：接口与数据模型预留，界面可配置但标注"开发中"。

&#x20;

3.5 专业文档导出 (Pro Export) — 预留

业务价值：解决"信息如何交付"的问题，满足商务场景的专业呈现需求。

核心能力：

• 支持将选定文章导出为高规格 Word 文档。

• 自动嵌入固定 Logo、动态背景水印（用户可自定义文字）、多级目录与导读页。

• 文档风格统一，适合对外交付给客户、合作伙伴或上级单位。

MVP 交付：接口与数据模型预留，界面可配置但标注"开发中"。

&#x20;

3.6 智能订阅与邮件通知 (Subscription) — 预留

业务价值：解决"信息如何触达"的问题，实现从"人找信息"到"信息找人"。

核心能力：

• 用户自定义主题词 + 目标网站 + 接收邮箱，灵活配置关注范围。

• 每日 09:00 自动扫描过去 24 小时的新入库文章，精准匹配关键词。

• 以 HTML 邮件形式推送汇总，排版美观，支持原文链接直接跳转。

• 提供一键退订与配置修改入口，尊重用户选择权。

MVP 交付：订阅配置可正常提交入库，邮件发送逻辑预留（界面提示"开发中"）。

6\. 应用落地方式

6.1 MVP 阶段（第 1\~4 周）

目标：验证核心数据闭环，产出可演示的最小可用系统。

交付形式：

• 部署在单台服务器或本地开发机的 Docker Compose 环境。

• 管理员通过 Web 后台手动提交爬取任务。

• 每日自动生成 Word 日报，支持下载。

• AI 分类与摘要可正常运行，人工抽检准确率。

• 微信、邮件、专业导出模块界面可见，但标注"开发中"。

适用对象：内部团队试用、小范围种子用户测试。

&#x20;

6.2 推广阶段（第 5\~8 周）

目标：完善分发渠道，实现从"工具"到"产品"的跨越。

交付形式：

• 接入微信公众号 API，实现真正的草稿箱推送。

• 接入 SMTP / 邮件推送服务，订阅邮件真实送达。

• 实现专业 Word 导出功能，支持 Logo、水印、目录。

• 引入基础用户体系（注册/登录），支持多租户数据隔离。

• 部署至生产域名（shixun.com），配置 HTTPS 与 CDN。

适用对象：政策研究机构、行业协会、科技媒体等付费或合作客户。

&#x20;

6.3 规模化阶段（第 9\~12 周及以后）

目标：提升系统吞吐量与智能化水平，支撑商业化运营。

交付形式：

• 爬虫支持插件化扩展，快速适配新目标网站。

• AI 模型路由：按分类或成本自动选择最优大模型供应商。

• 引入语义搜索与推荐系统，实现"猜你想看"。

• 数据看板：提供文章趋势分析、分类分布统计、用户行为洞察。

• 企业版 SaaS：支持团队协同、权限管理、API 开放平台。

适用对象：大中型企业战略部、咨询公司、政府情报中心。

7\. 预期形成的成果形式

7.1 软件系统

• Web 应用：shixun.com 管理后台，支持文章库浏览、任务提交、日报下载、系统配置。

• API 服务：完整的 RESTful API 集合，为未来移动端、小程序或第三方集成提供能力。

• 管理后台：面向运营人员的可视化配置界面，包括分类管理、模板管理、用户管理。

7.2 内容资产

• 每日 Word 情报汇编：固定格式的专业日报文档，可直接用于内部流转或对外发布。

• 微信公众号推文：经过统一排版与封面设计的高质量图文内容。

• 订阅邮件：HTML 格式的精准情报推送，提升用户粘性与品牌认知。

7.3 技术资产

• 爬虫适配层：可复用的网页内容提取框架，支持快速新增目标站点。

• AI Prompt 模板库：经过调优的分类与摘要 Prompt，可直接复用于其他文本分析场景。

• 文档生成引擎：基于 python-docx 的高阶封装，支持水印、目录、导读等复杂排版需求。

7.4 知识产权

• 产品 UI/UX 设计稿与交互规范。

• 系统架构文档与接口契约（即本文档）。

• 部署手册与运维指南。
