# 拾讯 UI 重新设计方案

日期：2026-05-03
状态：**已决策（待实施）**

## 已确认的设计方向

- **风格**：Linear 暗色风（深色主题）
- **配色**：`#0a0a0b` 背景、`#1f1f23` 边框、`#5e6ad2` 紫蓝品牌色
- **布局**：左侧固定导航栏 + 右侧内容区（参考 Linear App）
- **品牌色系**：紫蓝色 (`#5e6ad2`)

## 待实施页面

1. **整体布局** — 侧边栏导航 + ⌘K 命令入口 + 深色主题
2. **Login** — 暗色风格登录页
3. **Dashboard** — 统计卡片 + 每日采集柱状图 + 分类分布
4. **Articles** — 筛选栏 + 文章卡片列表 + 分页
5. **Tasks** — 任务表格 + 状态徽标
6. **Admin/Distribution** — 分发配置 CRUD + 模态框

## 待后续确认

- 侧边栏是否可折叠
- 是否要暗/亮色切换
- UI 组件库选用（shadcn/ui 或其他）
