## 第4页 | 核心能力 1：智能爬虫引擎

**标题**：核心能力 1 — 智能爬虫引擎

**左半页**（技术点）：

**双渲染策略**（按需降级）
- httpx 快速路径：静态页秒级抓取，零资源消耗
- Playwright 渲染：动态页自动滚动 + JS 执行

**反检测机制**

- 随机 User-Agent + 视口尺寸

**智能发现**
- BFS 从 1 个入口页发现 50+ 文章链接
- 链接评分排序，优先爬取高质量内容
- 自动翻页，不消耗 depth 预算

## 第5页 | 核心能力 2：多标签智能分类

**标题**：核心能力 2 — 多标签智能分类

**左半页**（技术点）：

**11 个行业标签**
最新政策 · 数字经济 · 人工智能 · 数据要素 · 通信
申报 · 潜在商机 · 具身智能 · 车路云协同 · 新型工业化 · 算力

**LLM 分类机制**
- 输入：文章标题 + 正文摘录（~4000 tokens）
- 输出：每个标签的置信度分数（0~1）+ 关键词
- 自动筛选 top-3 高置信标签
- 置信度阈值 0.3，兜底"未分类"

**状态机驱动**
```
raw → analyzing → processed
          ↓
    failed_retryable（自动重试）
    failed_permanent（永久失败）
    analyzing 超时自动回退（5分钟）
```

- 截图1：文章详情页，展示 AI 分类标签和置信度条
- 截图2：分类标签管理页面（11个标签）

**关键数据**：
> 分类准确率 95%+ | 平均分析耗时 X 秒/篇

**演讲稿**（30秒）：
> 分类环节调用平台 LLM，给 11 个行业标签打分。每篇文章的标题和正文摘录送入模型，输出每个标签的置信度。系统自动取 top-3，阈值 0.3 过滤低置信结果。整个过程由状态机驱动，失败自动重试，超时自动回退，保证稳定性。

## 第7页 | 创新点

**标题**：创新性

**四个创新点**（2x2 网格布局）：

### 创新1：双渲染引擎（按需降级）
- 80% 静态页走 httpx，秒级完成
- 20% 动态页降级 Playwright
- 节省 70% 渲染资源，提速 3 倍

### 创新2：轻量日期预筛
- 在 HTML head 层提取日期（meta/time 标签）
- 爬取前快速判断是否在目标日期范围内
- 避免无效内容处理，节省 token

### 创新3：AI 分析状态机
- raw → analyzing → processed 完整生命周期
- 失败自动重试（可重试/永久失败分类）
- analyzing 超时自动回退（5分钟阈值）
- 保证系统稳定性，无人值守运行

### 创新4：动态模型预设
- 内置 Kimi / OpenAI / DeepSeek 快捷选择
- 用户自定义模型：保存即生成快捷按钮
- 支持无限扩展，一键切换不同模型

**演讲稿**（30秒）：
> 创新性体现在四个方面。双渲染引擎按需降级，节省大量资源。轻量日期预筛在爬取前就过滤掉不匹配的文章，避免浪费 token。AI 状态机保证分析流程稳定可靠，无人值守也能自动恢复。动态模型预设让用户灵活切换不同算力平台。

## 第8页 | 数据安全与隐私

**标题**：数据隐私风险识别与处理

**三项措施**（卡片式布局）：

### 1. 本地化部署
- 数据存储在自有 PostgreSQL 数据库
- 不上传第三方平台，完全自主可控
- Docker 容器化部署，环境隔离

### 2. 敏感信息脱敏
- API Key 仅显示前 8 位 + `***`
- 系统设置页面防止密钥泄露
- 日志中不记录完整 Key

### 3. 域名白名单机制
- 管理员配置允许爬取的域名列表
- 支持精确匹配 / 后缀匹配 / 正则匹配
- 自动记录来源，避免越界采集

**底部**：
> 识别到的风险：API Key 泄露、越界爬取、数据过度留存
> 处理方式：脱敏 + 白名单 + 本地存储

**演讲稿**（20秒）：
> 数据安全方面，我们识别了三个主要风险并做了处理。API Key 脱敏防止密钥泄露，域名白名单防止越界爬取，数据本地存储确保完全可控。
